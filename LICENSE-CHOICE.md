# Choose a licence before public release

A public GitHub repository is visible, but visibility alone does not grant permission to reuse, modify, or redistribute its code.

Two suitable permissive options are:

| Licence | Suitable when |
| --- | --- |
| MIT | You want a short, widely understood licence with minimal conditions. |
| Apache-2.0 | You want a permissive licence with an express patent grant and more detailed terms. |

For a small educational reference implementation, MIT is often the simplest choice. This file is not itself a software licence. After deciding, add the complete official licence text as a root-level file named `LICENSE`, including the correct copyright year and holder.
